# Weekly Performance Report Generation
  Automatically Generate Business Performance Reports on a scheduled basis

## What this automation does
  Video Demo: https://www.youtube.com/watch?v=aWUKizaVnXQ
  
  This automation generates the report by:
  - Pulls business statistics from CRM
  - AI Agent analyzes statistics and generate report
  - Report includes Executive summary, Key metrics, Key highlights, and Recommended actions
  - Report emailed to team

## Who this is for
  - Trade Businesses
  - Sales team
  - Any business that is looking to grow

## Key features
  - CRM Integration
  - AI powered qualification agent
  - works 24/7 with no manual input
  - Instant emails get sent to team
  - KPI Report Generated Automatically

## How it works
  1) Business stats info pulled from CRM
  2) Information is processed by AI Agent
  3) AI Agent Generates executive summary, key metrics, key highlights, and recommended actions
  4) Report Generated
  5) Report emailed to team automatically 

## Tech Stack
  - n8n (workflow automation)
  - OpenAI chat model (gpt-5-mini)
  - Gmail (communication channel)
  - Google sheets (lead storage)
  - HTML (Report template)
