# Review Request Automation
  Automatically executes the review follow up for completed jobs

## What this automation does
  Video Demo: https://www.youtube.com/watch?v=EmTRSH2n7C4
  
  This automation qualifies the customer by:
  - Detect completed jobs on CRM
  - Process customer information
  - AI Agent composes follow up email
  - Email sent to client with link to review

## Who this is for
  - Electricians
  - Plumbers
  - Real estate agents
  - service based businesses
  - Product selling businesses

## Key features
  - CRM Integration
  - AI powered qualification agent
  - works 24/7 with no manual input
  - Instant emails get sent to team

## How it works
  1) Team member adds completed job details onto CRM
  2) Wait 1 day
  3) AI Agent gathers job details & composes follow up review request email
  4) Emails gets sent to client

## Tech Stack
  - n8n (workflow automation)
  - OpenAI chat model (gpt-5-mini)
  - Gmail (communication channel)
  - Google sheets (Completed jobs)
