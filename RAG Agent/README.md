# RAG AI Agent
  A RAG Agent that provides online customer support for queries and questions.

## What this automation does
  Video Demo: https://www.youtube.com/watch?v=tNhl72S25D8
  
  This automation works by:
  - Uploading important documents
  - Scans important documents
  - Answers customer questions
  
## Who this is for
  - Electricians
  - Plumbers
  - Real estate agents
  - Businesses that value online customer service experience

## Key features
  - AI powered agent
  - LLM Models
  - works 24/7 with no manual input
  - Real time conversation

## How it works
  1) Downloads important documents containing key information
  2) Scans documents as customer asks questions
  3) Replies to customer in simple straight forward answers
  4) Provides further support and recommendations

## Tech Stack
  - n8n (workflow automation)
  - Open AI chat model (gpt-5.6-terra)
  - n8n chat webpage
